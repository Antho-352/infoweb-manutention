# Mots-clés — stratégie de contenu (à rechercher : volume + difficulté)

> Volumes « (H) » = déjà connus via tes exports Haloscan (juillet 2026). Les
> autres sont à rechercher. Intention : **AFF** = affiliation (achat en ligne),
> **LEAD** = devis (gros matériel, concession/location), **AUTORITÉ** = trafic
> + maillage, pas de vente directe.

## Le principe — 3 étages qui se maillent

1. **Pages d'affiliation** (money pages) : comparatifs / guides d'achat, intention transactionnelle. C'est là qu'est le revenu.
2. **Articles « pousseurs »** : informationnels, forte demande, qui **maillent vers la money page** correspondante (« comment choisir X » → comparatif X).
3. **Blog / piliers** : autorité réglementaire + guides, maillent vers money pages **et** pages à devis.

Règle d'or : **on n'affilie que ce qui s'achète en ligne** (petit matériel). Le gros matériel = devis.
